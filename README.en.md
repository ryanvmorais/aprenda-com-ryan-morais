Code, exercises and tools that go with the channel. I explain programming, artificial intelligence and cybersecurity by showing the why, not just the command, and I build in public what I teach.

The channel, podcast, newsletter, blog and website are in Portuguese (Brazil).

---

## 🎯 What I talk about

- **Programming:** logic, Python and end-to-end web development, from the database to the interface.
- **Cybersecurity:** real risks for the people who build software and the people who use it, with a focus on web application and email security.
- **Artificial intelligence:** what AI changes for programmers and how to use it with judgment, without hype.
- **Good practices:** tests, automation, continuous delivery and up-to-date dependencies, so software works and stays maintained.

## 🛠️ How to use this repository

1. **Mini projects:** open the project folder and follow its README to install and run it.
2. **Larger projects:** open the project's repository and follow its README.
3. **Questions:** open an [Issue here](https://github.com/ryanvmorais/aprenda-com-ryan-morais/issues) (mini projects and general topics) or in the project's own repository. You can also use the [contact](https://ryanmorais.com.br/contato/) page on the website.
