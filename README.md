# 🚀 Aprenda Python, IA e Cibersegurança | Material de apoio do canal Ryan Morais

Código, exercícios e ferramentas que acompanham o canal. Eu explico programação, inteligência artificial e cibersegurança mostrando o porquê, não só o comando, e construo em público o que ensino.

## 🎯 Sobre o que eu falo

- **Programação:** lógica, Python e desenvolvimento web de ponta a ponta, do banco de dados à interface.
- **Cibersegurança:** riscos reais para quem desenvolve e para quem usa, com foco em segurança de aplicações web e de e-mail.
- **Inteligência artificial:** o que a IA muda para quem programa e como usá-la com critério, sem exagero.
- **Boas práticas:** testes, automação, entrega contínua e dependências em dia, para o software funcionar e se manter.

## 🛠️ Como usar este repositório

1. **Mini projetos:** abra a pasta do projeto e siga o README dele para instalar e rodar.
2. **Projetos maiores:** abra o repositório do projeto e siga o README dele.
3. **Dúvidas:** abra uma [Issue aqui](https://github.com/ryanvmorais/aprenda-com-ryan-morais/issues) (mini projetos e assuntos gerais) ou no repositório do projeto. Também dá para usar a página de [contato](https://ryanmorais.com.br/contato/) do site.
